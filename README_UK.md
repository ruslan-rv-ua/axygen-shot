# Axygen Shot

[![CI](https://github.com/ruslan-rv-ua/axygen-shot/actions/workflows/ci.yml/badge.svg)](https://github.com/ruslan-rv-ua/axygen-shot/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/ruslan-rv-ua/axygen-shot)](https://github.com/ruslan-rv-ua/axygen-shot/releases/latest)

Портативний CLI-інструмент для Windows, який захоплює вікна застосунків як скріншоти.
Розроблений насамперед для незрячих розробників, яким потрібен швидкий, клавіатурний
робочий процес для захоплення, збереження та передачі скріншотів ШІ-асистентам
для візуального опису.

**[English version](README.md)**

## Що він робить

- Захоплює конкретне вікно застосунку за назвою процесу або підрядком заголовка
- Зберігає PNG-скріншоти з позначками часу у підтеку проекту
- Копіює результат у буфер обміну (шлях до файлу, зображення або обидва)
- Відтворює звукове підтвердження, щоб ви знали про успіх без погляду на екран
- Працює як фоновий демон із глобальною гарячою клавішею для повторних захоплень

## Встановлення

Завантажте `shot.exe` та `shot-watch.exe` з
[останнього релізу](https://github.com/ruslan-rv-ua/axygen-shot/releases/latest)
і помістіть обидва файли в одну теку, що є у вашому `PATH`.

Вимоги: Windows 10 або новіша (x86-64).

> **Чому два файли?** `shot.exe` — консольний додаток, оболонка чекає на нього
> синхронно. `shot-watch.exe` — GUI-додаток, демон у треї працює без спалаху
> консольного вікна. Деталі в [ADR-002](docs/ADR-002-dual-binaries.md).

## Швидкий старт

```
cd my-project
shot --init --process=myapp.exe
shot
```

Це створить `shot.toml` у поточній теці, захопить вікно `myapp.exe`, збереже
скріншот у `screenshots/`, скопіює шлях до файлу в буфер обміну та відтворить
звук підтвердження.

## Конфігурація

`shot.toml` розміщується в корені проекту (поруч з `.git`). Інструмент шукає
його вгору від поточної теки.

```toml
# shot.toml
process   = "myapp.exe"          # збіг за назвою процесу
# title   = "MyApp"              # або за підрядком заголовка (логіка АБО)
folder    = "screenshots"        # підтека для збереження (за замовчуванням: "screenshots")
clipboard = "path"               # "path" | "image" | "both" (за замовчуванням: "path")
# hotkey  = "Win+F12"            # гаряча клавіша watch-режиму (за замовчуванням: "Win+F12")
```

Усі поля, крім `process` або `title`, необов'язкові та мають розумні значення
за замовчуванням.

## Використання

```
shot                        Захопити одноразово та вийти
shot my-label               Захопити з довільною міткою у назві файлу
shot --watch                Запустити фоновий демон із гарячою клавішею
shot --list-windows         Показати всі доступні вікна
shot --check                Перевірити конфігурацію без захоплення
shot --init                 Створити шаблон shot.toml у поточній теці
shot --init --process=app   Створити заповнений shot.toml
shot --version              Показати версію
shot --help                 Показати довідку
```

### Перевизначення з командного рядка

Будь-яке значення конфігурації можна перевизначити в командному рядку:

```
shot --process=other.exe --clipboard=both --folder=snaps "my label"
```

### Watch-режим

```
shot --watch
```

Запускає фоновий демон, який слухає глобальну гарячу клавішу (за замовчуванням
`Win+F12`). У системному треї з'являється іконка з контекстним меню для
перезапуску та виходу. На системі одночасно працює лише один демон (контролюється
іменованим м'ютексом).

## Вивід

При успіху інструмент друкує у stdout:

```
status: ok
file: C:\projects\myapp\screenshots\2025-01-15_143022345_myapp-main-window.png
clipboard: path
```

При помилці друкує у stderr та завершується з ненульовим кодом.
Звуковий зворотний зв'язок супроводжує обидва результати.

## Збірка з вихідного коду

Потрібен Rust 1.87 або новіший.

```
cargo build --release
```

Релізний бінарник знаходиться у `target\release\shot.exe` (та `target\release\shot-watch.exe`
для демона у треї).

## Структура проекту

| Файл | Призначення |
|------|-------------|
| `src/main.rs` | Точка входу `shot.exe` (CLI), диспетчеризація режимів |
| `src/lib.rs` | Спільний бібліотечний крейт (`axygen_shot`) |
| `src/bin/shot-watch.rs` | Точка входу `shot-watch.exe` (демон у треї) |
| `src/cli.rs` | Розбір аргументів командного рядка (clap) |
| `src/config.rs` | Пошук, валідація та ініціалізація TOML-конфігурації |
| `src/window_resolver.rs` | Перелік та пошук вікон |
| `src/capture.rs` | Захоплення вікна через PrintWindow/BitBlt |
| `src/storage.rs` | Генерація назв файлів та збереження PNG |
| `src/clipboard.rs` | Операції з буфером обміну (шлях та зображення) |
| `src/audio.rs` | Звуковий зворотний зв'язок через MessageBeep |
| `src/watch.rs` | Watch-режим: демон, гаряча клавіша, іконка у треї |
| `src/errors.rs` | Типи помилок та форматування |
